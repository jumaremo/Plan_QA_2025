# 🚀 Plan de Capacitación QA 2025

## 📊 Descripción del Proyecto

Sistema integral de capacitación para equipos de Quality Assurance con **11 componentes especializados** y **4 niveles de prioridad**, optimizado para reducir el tiempo de formación de 18 a 12 meses.

**🌐 Demo en vivo:** https://planqa2025.netlify.app/

---

## 🎯 Características Principales

### **✨ Sistema Modular Avanzado**
- **11 componentes** especializados de capacitación
- **Filtros dinámicos** por prioridad, componente y fuente
- **Banner de tiempo inteligente** que calcula duración por filtro
- **Exportación a Excel** con datos completos
- **Responsive design** para móvil y desktop

### **🏆 Sistema de Prioridades**
- 🏗️ **Fundamentos** (42h) - Base esencial QA
- 🤖 **Automatización** (89h) - Frameworks y herramientas
- ⚡ **Especialización** (156h) - Testing avanzado
- 🚀 **Vanguardia** (200h) - IA y tecnologías emergentes

### **📊 Optimización de Tiempo**
- **33% reducción** en tiempo de capacitación
- **Roadmap de 12 meses** vs 18 meses original
- **Priorización inteligente** de contenido

## 🚀 Instalación y Uso

### **🔧 Setup Local**

```bash
# 1. Clonar repositorio
git clone [URL_REPOSITORIO]
cd plan_qa_2025_V2

# 2. Abrir en servidor local
# Opción A: Live Server (VS Code)
# Opción B: Python simple server
python -m http.server 8000

# 3. Abrir en navegador
open http://localhost:8000
```

### **☁️ Deploy Automático**

El proyecto está configurado para **deploy automático en Netlify**:

1. **Push** a la rama `main`
2. **Deploy automático** a https://planqa2025.netlify.app/
3. **Verificación** inmediata de cambios
